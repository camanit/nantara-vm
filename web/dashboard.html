🔒 Rencana AMD SEV-SNP / Intel TDX ROADMAP 2026

Confidential Computing adalah salah satu fitur jangka panjang NantaraVM. Membutuhkan hardware server fisik dengan CPU AMD EPYC (Milan/Genoa) atau Intel Xeon Sapphire Rapids yang mendukung SEV-SNP/TDX.

⚠️ Fitur ini belum diimplementasi sama sekali. Kode saat ini hanya memiliki struktur placeholder. Implementasi nyata membutuhkan akses ke hardware khusus dan driver kernel Linux terbaru.
Langkah Implementasi yang Direncanakan:

1. ✅ Definisi struktur data SevSnpManager (selesai)
2. 🔨 KVM_SEV_SNP_LAUNCH_START ioctl (belum)
3. 📋 Guest memory encryption via PSP (belum)
4. 📋 Attestation report dari AMD PSP (belum)
5. 📋 KMS secret injection via vsock (belum)

⚡ Rencana XDP / eBPF Networking ROADMAP

XDP (eXpress Data Path) dan eBPF sockmap adalah teknik jaringan kernel Linux untuk throughput dan latensi ultra-rendah. Ini adalah fitur enterprise jangka menengah NantaraVM.

⚠️ eBPF dan XDP saat ini hanya berupa println!() placeholder. Belum ada program eBPF yang dimuat ke kernel.
Stack yang Direncanakan:

📋 Library: aya-rs atau libbpf-rs untuk load program eBPF
📋 TAP interface untuk VirtIO network
📋 XDP hook di NIC driver untuk DDoS mitigation
📋 BPF_MAP_TYPE_SOCKMAP untuk zero-copy VM-to-VM forwarding

⏱️ Rencana Snapshot & Restore Engine ROADMAP

Snapshot dan lazy restore via userfaultfd adalah fitur penting untuk efisiensi spawning banyak VM. Teknisnya: halaman memori hanya dimuat ketika diakses (copy-on-write).

⚠️ LazyRestoreEngine saat ini hanya berupa stub. Belum ada snapshot yang bisa disimpan atau di-restore.
Rencana Implementasi:

1. 📋 Serialisasi state vCPU (register, VMCS)
2. 📋 Dump dirty pages via KVM_GET_DIRTY_LOG
3. 📋 Simpan snapshot ke file disk
4. 📋 userfaultfd handler untuk lazy page load saat restore
5. 📋 Target restore latency: < 50ms (realistis awal)
