Membangun Hypervisor MicroVM
Pertama Karya Indonesia

NantaraVM adalah proyek open-source ambisius untuk membangun MicroVM Hypervisor berbasis Rust yang aman, cepat, dan berdaulat. Terinspirasi dari Firecracker (AWS) dan Cloud Hypervisor (Intel), namun dikembangkan sepenuhnya oleh engineer Indonesia.

🏗️ Arsitektur yang Dibangun

Desain modular berbasis Rust yang mengikuti pola hypervisor production seperti Firecracker & Cloud Hypervisor.

⚙️

KVM VMM Core

Wrapper Rust untuk Linux KVM ioctl. Alokasi guest RAM via mmap, create VM FD, dan vCPU management menggunakan library kvm-ioctls.

Status: 🔨 Implementasi aktif

💾

VirtIO Device Bus

Abstraksi perangkat VirtIO via MMIO transport. Termasuk VirtioBlock, VirtioNet, dan VirtioVsock dengan trait interface yang bersih.

Status: 🔨 Desain selesai, implementasi queue aktif

🛡️

Process Jailer

Isolasi proses dengan Linux namespaces dan seccomp BPF. Rancangan mengikuti pola Firecracker Jailer untuk keamanan multi-layer.

Status: 📋 Desain, implementasi penuh direncanakan

🌐

REST API Management

API server untuk kontrol lifecycle VM: start, pause, resume, snapshot. Akan mendukung koneksi TCP agar bisa diakses dari web dashboard.

Status: 📋 TCP binding direncanakan

🔒

Confidential Computing

Dukungan AMD SEV-SNP dan Intel TDX untuk enkripsi memori hardware. Fitur ini membutuhkan server fisik dengan CPU yang mendukung.

Status: 🎯 Roadmap jangka panjang

📦

Container Runtime Shim

Antarmuka containerd-shim-v2 untuk integrasi Kubernetes. Memungkinkan container berjalan di dalam MicroVM yang terisolasi.

Status: 🎯 Roadmap jangka menengah

🔨 Build dari Source Code

Untuk developer yang ingin mencoba & berkontribusi. Membutuhkan Linux + Rust toolchain.

# Clone repository git clone https://github.com/nantara-vm/nantara-vm.git cd nantara-vm # Build (membutuhkan Linux, Rust 1.75+) cargo build # Jalankan (stub/demo mode di non-Linux) cargo run

⚠️ Catatan: Fitur KVM penuh hanya berjalan di Linux dengan /dev/kvm tersedia.
