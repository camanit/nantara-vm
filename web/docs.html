Bab 1: Panduan Instalasi 1-Click (Windows & Linux)

A. Instalasi di Windows (1-Click Installer)

NantaraVM menyediakan installer otomatis untuk sistem operasi Microsoft Windows:

  1. Unduh repositori atau jalankan perintah 1-Click di PowerShell (Administrator): 
    iwr -useb https://raw.githubusercontent.com/camanit/nantara-vm/main/web/install.ps1 | iex
  2. Atau cukup double-click file install.bat di folder project Anda.
  3. Installer akan memasang engine ke C:\Program Files\NantaraVM dan otomatis membuat shortcut "NantaraVM Workstation" di Desktop Windows Anda!

B. Instalasi di Linux / WSL2 (1-Click Shell Script)

Jalankan satu baris perintah di terminal Linux (Ubuntu / Debian / Fedora / WSL2):

curl -fsSL https://raw.githubusercontent.com/camanit/nantara-vm/main/web/install.sh | sh

Bab 2: Penggunaan NantaraVM Workstation Manager (GUI)

Antarmuka NantaraVM Workstation Manager dirancang untuk kemudahan manajemen Mesin Virtual seperti VMware Workstation & Oracle VirtualBox.

🌐 Akses Dashboard Web melalui browser Anda di https://nantara.cloud/dashboard.html atau melalui tombol shortcut di Desktop Windows.

Fitur Utama Dashboard:

  • ➕ Buat VM Baru (New VM Wizard): Tentukan Nama VM, OS Guest (Windows 10/11, Ubuntu Linux, Alpine MicroVM), alokasi vCPU, RAM, dan file ISO.
  • ▶️ Start (Play): Booting Mesin Virtual secara instan menggunakan KVM engine & REST API backend.
  • ⏸️ Pause: Membekukan eksekusi vCPU & state memori sementara.
  • ⏹️ Shutdown: Mematikan sesi MicroVM secara aman.
  • ⚙️ Pengaturan VM: Konfigurasi VirtIO GPU, TAP Network, dan Sandboxing Security.

Bab 3: Perintah Terminal CLI & Parameter Options

Untuk pengembang dan administrator server, NantaraVM dapat dijalankan secara langsung via Command Line Interface (CLI):

sudo nantara-vm --bios OVMF.fd --drive win10.qcow2 --net nantara-tap0 --display virtio-gpu --jail
Parameter CLIFungsi / DeskripsiContoh Penggunaan
--bios <path>Memuat Firmware BIOS / UEFI OVMF Bootloader--bios OVMF.fd
--iso <path>Membaca & mounting berkas ISO (El Torito parser)--iso windows10.iso
--drive <path>Menghubungkan disk image VirtIO Block Device--drive disk.qcow2
--net <tap>Menghubungkan VirtIO Network TAP Interface--net nantara-tap0
--display virtio-gpuMengaktifkan 1024x768 32-bit RGBA Display Engine--display virtio-gpu
--jailMengaktifkan Seccomp-BPF & Landlock LSM Isolation--jail

Bab 4: Keamanan Kernel & Sandbox Architecture

🛡️ Keamanan Berlapis (Multi-Layer Protection):
  • Seccomp-BPF Syscall Filter: Panggilan kernel BPF via seccompiler mengizinkan 70+ syscall legal dan menolak eksekusi berbahaya seperti execve dan ptrace.
  • Landlock LSM Filesystem Isolation: Mengunci akses direktori file sistem menggunakan panggilan kernel landlock_create_ruleset.
  • Snapshot Engine (`NANTSNAP`): Format binary file I/O menyimpan dan memuat ulang state RAM guest secara presisi.
